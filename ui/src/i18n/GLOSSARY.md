# UI translation glossary (English → Estonian)

One term, one translation — use these everywhere. Tone: plain, friendly, second
person singular ("sina": *vali*, *vajuta*, *sinu andmebaas*), short sentences,
no bureaucratic phrasing. Estonian quotation marks „…“. Times like "kell 07.00".

## Never translate
Product and feature names that are code or protocols: DbButler, PostgreSQL, SQL,
pg_stat_statements, HypoPG, pev2, MCP, Prometheus, Grafana, Slack, Teams, Discord,
Docker; SQL keywords and commands (VACUUM, ANALYZE, CREATE INDEX, CONCURRENTLY,
EXPLAIN, NOT VALID, lock_timeout …); setting, column, role and function names
(shared_buffers, n_live_tup, pg_monitor, pg_ls_waldir() …); lock mode names
(ACCESS EXCLUSIVE …); API values; URLs; keyboard keys (Esc, Enter).
